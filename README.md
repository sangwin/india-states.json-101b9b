# India States JSON

## Overview

A JSON dataset containing information about states and union territories of India.

## Source

Extracted from [Sangwin Gawande's Gist](https://gist.github.com/sangwin/101b9b27f38deef2a12be1af42de50b9).

## Usage

Use `india-states.json` as a data source for:

- State and union territory dropdowns
- Address forms
- Location-based applications
- State selection in web applications
